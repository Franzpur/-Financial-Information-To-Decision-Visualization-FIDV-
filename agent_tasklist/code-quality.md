# 代码质量属的任务

隶属监理部。只在监理部委派时执行：监理部在本会话用 Task 并行派出；该类型未收录则父代理按监理部的单代派。只读本地 diff，不改文件。不打开 GitHub，不截图。截图只属于工程测试属。

## 四问

不增第五套理念。任一为否，本属不达标。

1. 代码是否服务这次功能的实现
2. 是否简洁
3. 是否与以往连贯（`ind-chain/CONCEPTS.md` 与既有结构，不另起一套）
4. 是否不外溢（不改这次任务以外的产品行为与文件）

## 父代理必须送来

与工程测试属、理念贯彻属同一份：业主原话、diff 路径、第 N 次送审。不附另外两属的结论。

## 交回

见 `agents/code-quality.md`。本属不写整单通过/打回。不审能不能跑，不审 `DESIGN.md`。
