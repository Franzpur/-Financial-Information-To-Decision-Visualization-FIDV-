# 工程测试属的任务

隶属监理部。只在监理部委派时执行：监理部在本会话用 Task 并行派出；该类型未收录则父代理按监理部的单代派。不改仓库文件。

## 判什么

这次改动所涉工程能否打开、是否有阻断性报错。用直接截取并观察影像判断是否达标。

有界面或启动行为：打开受影响入口（`Standard-Cube.app`，或 `http://127.0.0.1:8787/` 与改动落到的路由），截图，看画面是否就是这次要的结果。打开本地页、拉取页面的确认直接通过，不再问业主。

打不开，或有阻断性报错：不达标。只看图好不好看、不看是否达成该次任务：不算检验。

无界面：写明「无影像面」，并检查所涉入口仍可打开、不报错。不能写成看过画面。

## 父代理必须送来

与代码质量属、理念贯彻属同一份：业主原话、diff 路径、第 N 次送审。不附另外两属的结论。

## 交回

见 `agents/engineering-test.md`。本属不写整单通过/打回。
