# 子代理任务库

角色定义在 `agents/`。这里放每个角色对应的任务，创建角色之前先把任务放进来。

- `DESIGN.md`：理念贯彻属的任务（三条正文不因部门改名而改）
- `supervision.md`：监理部的任务（三监报告）
- `engineering-test.md`：工程测试属的任务
- `code-quality.md`：代码质量属的任务
- `AESTHETIC.md`：美工部的美学真源
- `art-department.md`：美工部的派用步骤
- `INFORMATION.md`：信息部的数据真源（词条 / 地图）
- `INFORMATION-manage.md` / `INFORMATION-clean.md` / `INFORMATION-request.md`：信息部三分部
- `information-department.md`：信息部的派用步骤
- `general-staff.md`：总参谋部的任务（含调度/管理非排除子代理；细则亦见 `RULE.md`）
- `archive-department.md`：档案部的任务
- `secretary.md`：书记的任务（worklog）
- `clerk.md`：秘书的任务（报告/讲稿；纸面美学 skill `clerk-showable-report`）
- `operations.md`：运维的任务（ops-log）
- `RULE.md`：父代理派任务时怎么写
