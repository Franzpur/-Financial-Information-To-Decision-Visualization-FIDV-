# Standard-Financial-Charting (Ind-Chain)

Modular 3D industry-chain explorer backed by SQLite.

**Concepts (ZH/EN):** see [`CONCEPTS.md`](./CONCEPTS.md) before changing camera, axes, pull, or focus UX. Code tags look like `[C-SLICE]`, `[C-STDVIEW]`.

## Layout

```
Ind-Chain/
  data/           layers.json, companies.json, nvda-revenue-links.json (source of truth); ind_chain.db (generated)
  server/         1:1 backend modules: app.py (BE-HTTP), bics_hier.py (BE-BICS-HIER), bics_entity.py (BE-BICS-ENTITY),
                  listing.py (BE-BICS-AREA), bundle_dispatch.py (BE-BUNDLE), db.py (BE-DB-DEMO),
                  db_shadow.py (BE-DB-SHADOW), nvda_links.py (BE-NVDA-LINKS), chain_layout.py (BE-NVDA-LAYOUT)
  CONCEPTS.md     bilingual concept target library (agent continuity)
  web/            index.html, list.html, cube.html, css/, js/ (incl. nav.js FE-NAV, bondChart.js FE-FOCUS), vendor/three/
  shell/          Swift sources of the native app shell (window, back-end child, error panel, selftest)
  scripts/        build-standard-financial-charting-app.sh, package-standard-financial-charting.sh,
                  regress_all.sh, regress_api_golden.py, regress_app_lifecycle.sh, seed.py, set-command-icon.sh
  assets/         launcher icons
```

Root entry: `../Standard-Financial-Charting.app` is a universal Swift shell (NSWindow + WKWebView). It starts `server/app.py` (with the embedded Python in a packaged app, otherwise a system `python3`) as its own child on a free loopback port, loads it, supervises it (restart on crash/hang, error panel on failure) and stops it when the window closes. Rebuild: `./scripts/build-standard-financial-charting-app.sh` (takes no arguments; the old Python launcher window was retired in P4, last commit with it: `019af67`).

## Run

```bash
# Finder double-click, or (from this directory):
open ../Standard-Financial-Charting.app
# development path (http://127.0.0.1:8787/):
python3 server/app.py
# optional: seed first
python3 scripts/seed.py && python3 server/app.py
```

## Packaging, embedded Python, signing

```bash
bash scripts/package-standard-financial-charting.sh               # dist/internal/  (with entities data; internal only)
bash scripts/package-standard-financial-charting.sh --no-entities # dist/noentities/ (external variant, -noentities zip)
bash scripts/fetch-embedded-python.sh                              # only the runtime step (cached in ../build/python-runtime/)
```

The package embeds python.org Python 3.14.8 (universal2; pinned URL and SHA-256 in `fetch-embedded-python.sh`; the installer must be signed by the Python Software Foundation) under `Contents/Frameworks/Python.framework`, trimmed (no tkinter, IDLE, tests, pip, headers) and precompiled. No system Python is needed. The shell prefers it, then a system Python 3.9+ (`backend.log` first lines show `python=… source=bundled|system`). Signing is `SFC_SIGN_IDENTITY` / `SFC_NOTARY_PROFILE` driven; currently ad hoc and not notarized (no Developer ID on this machine). Details and the owner's one-time steps: root `README.md`, section "Signing and notarization".

## Environment

| Variable | Meaning | Check |
|----------|---------|-------|
| `SFC_PORT` | Port for the back end (unset: 8787). The shell sets a free port. | integer 1024–65535, otherwise exit 2 |
| `SFC_PARENT_PID` | Back end exits when this process disappears (set by the shell). | optional |
| `SFC_DATA_DIR` | Directory for the DB (app path: user Application Support dir; unset: `Ind-Chain/data/`). | absolute, creatable, writable, otherwise exit 2 |

## Regression

Run with no other app instance or Ind-Chain back end running (the scripts refuse otherwise and never kill what they did not start).

```bash
bash scripts/regress_all.sh capture   # on a known-good baseline: golden responses -> ${SFC_GOLDEN:-${TMPDIR:-/tmp}/sfc-golden}
bash scripts/regress_all.sh quick     # module graph, static checks, API golden compare (60 requests)
bash scripts/regress_all.sh full      # quick + selftest + lifecycle for the repo app and the dist/internal, dist/noentities packages
```

Golden responses contain third-party derived data: keep them outside the repo. `--help` lists the variables.

`data/ind_chain.db` is generated by `seed.py` or on first start (`ensure_db`); the app path keeps its own copy in the user data dir. Do not commit it. Demo Company (ticker `DEMO`) carries `bond_schedule`. On `/cube`, search `DEMO` and click the hit to open the company focus stage with the bond sparkline; plane pick keeps the right detail only.

Open http://127.0.0.1:8787/ — **engineering homepage** (BICS L1). The header search on L1–L3 lists matches over the page. Up/down moves the highlight; Enter fills the box with that ticker, and Enter again opens its primary L4 list (`/list?bics=<L4>&q=<ticker>`). Type `/cube` in that same box for a demo-cube hit; click or Enter opens bare `/cube` (no header button). An L4 list can sort by primary-row revenue. From an L4 list, click a company to open `/cube?ticker=`. Backspace there returns to /list?bics=<primary L4>; on the list and each home board it follows the breadcrumb’s previous link, and the level-1 board goes to /. On bare `/cube`, search `DEMO` for Demo Company (focus stage + bond sparkline). On `/cube?ticker=NVDA`, the cube builds **dynamic BICS L4 slices** (one wall per distinct primary L4 among NVIDIA and screenshot-visible peers; slice name = L4 classification) with point-to-point **C-REV-LINK** edges (`data/nvda-revenue-links.json`). No demo-layer bridge; no shell fan/sector draw. Bare `/cube` has no revenue links.

Finder / Dock icon: `assets/sfc-launcher.icns` → `Standard-Financial-Charting.app/Contents/Resources/AppIcon.icns`. After replacing the asset, rebuild the app (preferred), or sync and re-sign with:

```bash
./scripts/set-command-icon.sh
```

## API

| Route | Purpose |
|-------|---------|
| `GET /api/health` | Liveness |
| `GET /api/meta` | Title + country labels |
| `GET /api/layers` | Slices + company counts |
| `GET /api/companies` | `?layer=&country=us\|intl&supply=1&q=` |
| `GET /api/companies/:id` | One company (ring-normalized) |
| `GET /api/bics/children` | BICS children of `?parent=` (omit = L1); includes ancestors |
| `GET /api/bics/locate` | `?q=` name or ticker → primary L4 hits (`exact` when one ticker identity) |
| `GET /api/bics/entities` | Companies whose **primary L4** is `?bics=` (one ticker; other L1 % on the row) |
| `GET /api/bics/node` | One BICS node `?code=` (any level 1–7) |
| `GET /api/bics/l1` | Compat: BICS level-1 sectors |
| `GET /api/bundle` | Bootstrap payload for the cube SPA |

Ring positions (`revScore`, `ring`, `ringCos`, `ringSin`) are computed server-side so the browser never embeds the company table. The 3D space itself is user coordinates `(s, x, y)` — see `web/js/coords.js`. Edit `LAYOUT` (or an object's coord) to move something; do not place scene objects with raw Three.js coordinates.
