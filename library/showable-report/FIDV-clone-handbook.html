有格子、没有公司 · 给队员

2026-10-06 · 接工作日志 #97–#99
本题只谈：首页已有 Communications 等分类格，但家数是 0，点进四级名单是空的。

1. 现象

从 GitHub 克隆完整仓库，用启动器打开首页：分类格子在，家数全是 0，点四级没有公司。

这不是网页坏了，也不是没连上网上的数据库。工程没有远程库。缺的是本机这份文件：class-3-coords/BICS-Classification/bics_entities_20261003.db。它不进 GitHub，要在本机用 Python 生成。

2. 简要原因

格子来自仓里的 JSON（已下载）。公司名单来自上面那份 .db（clone 不会带）。

ingest_20261003_entities.py 不是连接程序。它读取 DATA-SPACE/ 里的 Excel，在本机写出 .db。网页服务再打开这个文件。没跑过脚本，服务照样能开，只是没有公司可数。

3. 原理

Excel 是能对账的原表，进 GitHub。JSON 是分类标准，进 GitHub。SQLite 是脚本算过的查询切片（主业、空占比负号），故意不跟踪，避免仓里两套数。网页运行时不现场拆 Excel，所以要先 ingest 一次。

4. 怎么运行（电脑终端）

是的：在电脑的终端里输入命令（Mac：终端.app / Terminal；Windows：命令提示符或 PowerShell）。不要在浏览器地址栏里贴这些字。路径换成你克隆下来的文件夹（文件夹里应能看见 Open-AI-Cube.command 和 DATA-SPACE）。

第 0 步 打开终端，进入仓库根目录。可以把文件夹从访达拖进终端窗口，或自己改路径：

cd /Users/你的用户名/路径/FIDV

用 ls 看一眼：应列出 ai-chain、class-3-coords、DATA-SPACE。没有这些，说明 cd 还没进对地方。

第 1 步 安装读 Excel 的库（每台电脑做一次）：

pip3 install openpyxl

若提示 pip3: command not found，先安装 Python 3，或试 python3 -m pip install openpyxl。

第 2 步 生成成员库（Excel 更新后也再跑一次）。仍在仓库根目录：

python3 class-3-coords/BICS-Classification/ingest_20261003_entities.py

成功时终端会打印各 xlsx 的 kept=，最后一行类似 wrote … bics_entities_20261003.db rows=…。第一次可能要一两分钟。若报 missing source dir，是 DATA-SPACE 没下全，重新 clone 整个仓。

第 3 步 重新开工程页。服务在启动时读一次库，ingest 之后必须重启：

  1. 若终端里启动器还在跑：输入 quit 回车，或按 Ctrl+C。
  2. 再启动。Mac 可在访达里双击 Open-AI-Cube.command；或在同一终端输入：
./Open-AI-Cube.command

浏览器打开 http://127.0.0.1:8787/。格子上的家数应不再是 0，点四级应有公司名单。

不要用浏览器直接打开 html 文件。不要把 ingest 那行命令打进网页搜索框。
