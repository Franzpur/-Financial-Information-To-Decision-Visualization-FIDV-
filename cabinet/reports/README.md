# 内阁报告库

业主向内阁要可打印报告时，报告写在这里。

纸面与秘书读本同一套：纸色、墨色、细线、宋体。不另做一套皮。

不写入 `library/showable-report/`。

`FIDV-ai-chain-risk-charts.html` 是《AI产业链及其风险》。Bloomberg Intelligence 的 44 份不进入这份结论。配图在 `figures/`。

`FIDV-bank-chart-logic.html` 是《头部投行的画图逻辑》，用来对照可视化工程。同样不含 Bloomberg Intelligence，配图共用 `figures/`。

`FIDV-all-charts.html` 是制图展开。1172 张，按分析公司分列。图下中文是该图或该组图在原文里的观点，并注明来源和作者。配图在 `plates/`。
