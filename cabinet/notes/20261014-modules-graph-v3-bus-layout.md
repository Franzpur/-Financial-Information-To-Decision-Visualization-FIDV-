## 自检：旧图为何不好看

1. 区标题压在节点上（「立方体面」盖住 FE-CUBE-BOOT）；FE-LISTING-UI、BE-DEMO-DB、BE-CHAIN-LAYOUT 探出区框。
2. 线过长绕远：FE-API→BE-HTTP 绕整幅底部再爬到顶；BE-HTTP 向左出五条并行长轨缠在一起；AESTHETIC 两线沿右缘跑近全高。
3. 线仍穿过 FE-CUBE-BOOT、FE-COORD 等节点（旧版只算「软警告」）。
4. FE-API 小牌标题与节点文字重叠；API 框与「FE-API」节点双重套框，含混。
5. 三区比例失衡：后端一条细长柱，右侧大片空；图例占一大块且与图脱节。
6. 字号 8.5 过小（缩放后约 6pt）；整页图被压在两张表之后，不像展出页。
7. 节点米色底与淡黄区底糊在一起；箭头与短线、虚线节奏不清。

## 整改

- **总线式**：BE-HTTP 立成一根贴后端右缘的高条，子模块全部水平直连；FE-API 立成一根框外高条，居后端与前端之间；FE-GATE/LIST/CUBE-BOOT→FE-API 水平直线，FE-API→BE-HTTP 一条短契约线。
- 其余边只在节点边缘定端口，经 0–2 折的短通道；BUNDLE 四出两条嵌套通道，AESTHETIC 右缘两条嵌套通道。
- 区名改为跨框线的小标签，避开所有线；节点白底、边框随区变色；ID 用无衬线 9.4px；枢纽条加粗并竖排。
- 版式：图前置、整页一图；表后移并分页；图例三列（分区/边色/线型）。
- **硬检**（`bake_static.py::check_geometry`，不合格则不烘焙）：0 交叉、0 叠段、0 平行过近（<4.5）、0 线穿任何框、0 沿区框走线、端口落在源框缘、箭头止于目标框缘外 1.5、节点在区内留边、区与区不相扰、30 边无缺无余。并做过两种变异自测（故意交叉、故意穿框），均被查出。
- SVG 现由 Python 直接生成（原为前端 JS 绘制），页面无运行时布局。
